# Screenshots

Working screenshots of MediMate at each sprint. Every sprint folder holds the increment that was delivered in that sprint, so the visual progress can be followed week by week alongside the Git tags.

- **sprint-1**: secure foundation. Create a local account (hashed PIN plus fingerprint or face unlock) and reach the authenticated Home dashboard.
- **sprint-2**: manage medicines (add, list on Home, edit, delete), stored offline. Added at the end of Sprint 2.
- **sprint-3**: find drug information (search openFDA, scan a barcode, cached detail). Added at the end of Sprint 3.
- **sprint-4**: interaction and warning screening, dose reminders, and the GDPR profile. Added at the end of Sprint 4.
- **sprint-5**: polish, accessibility and release. Added at the end of Sprint 5.
